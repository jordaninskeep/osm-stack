QGIS (QuickOSM)

Settings → Advanced → Overpass API, then replace the server URL. QuickOSM's presets and its own query builder work unchanged.

Python

import overpy
api = overpy.Overpass(url="<endpoint>")
r = api.query('[out:json];node["amenity"="cafe"](39.94,-83.02,39.98,-82.96);out;')
print(len(r.nodes))
import requests
r = requests.post("<endpoint>",
                  data={"data": '[out:json];node["amenity"="cafe"](39.94,-83.02,39.98,-82.96);out;'},
                  auth=("username", "password"))
r.json()["elements"]

What is in it

Coveragethe extract this server was built from — not the whole planet
Freshness…
HistoryCurrent data only. Element versions and timestamps are kept, so out meta; works; usernames are stripped by the upstream extract.
AreasBuilt, so area[name="…"] and is_in work.

Queries outside the covered region return nothing rather than an error, which looks identical to a query that legitimately matched nothing.

Two things that will cost you an afternoon

out tags geom silently drops relation geometry. tags means tags-only, and a relation's geometry lives in its members — so you get a bounding box and nothing to draw. Use plain out geom; when you want relation geometry.
Elements come back nodes, then ways, then relations. A limit like out geom 100; truncates in that order, so a low cap can return only nodes and no polygons at all. Cap generously, or query one type at a time.

Also worth knowing: out geom on a relation expands every member way, so a handful of boundary relations can turn one query into megabytes. out tags bb; gives you the extent instead, which is usually what you wanted.
